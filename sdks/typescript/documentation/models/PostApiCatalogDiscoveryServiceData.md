# PostApiCatalogDiscoveryServiceData

Information about the discovered service.

**Properties**

| Name              | Type                                                                                                          | Required | Description                                                                                                                                                  |
| :---------------- | :------------------------------------------------------------------------------------------------------------ | :------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| name              | string                                                                                                        | ✅       | The service's name.                                                                                                                                          |
| version           | string                                                                                                        | ❌       | The service's version.                                                                                                                                       |
| providerServiceId | string                                                                                                        | ❌       | The ID of the service in the source registry. If you do not pass this property, the system uses the `{name}:{version}` value.                                |
| description       | string                                                                                                        | ❌       | The service's description.                                                                                                                                   |
| sourceEnvironment | string                                                                                                        | ❌       | The service's source environment.                                                                                                                            |
| apiDefinition     | [PostApiCatalogDiscoveryServicesApiDefinitionData](PostApiCatalogDiscoveryServicesApiDefinitionData.md)       | ❌       | The API definition (specification) for the service. If you pass this with the `endpoints` array, this object is given preference and `endpoints` is ignored. |
| endpoints         | [ApiCatalogDiscoveryServiceEndpointsData](ApiCatalogDiscoveryServiceEndpointsData.md)[]                       | ❌       | A list of the service's endpoints. If you pass this with the `apiDefinition` array, this array is ignored.                                                   |
| tags              | string[]                                                                                                      | ❌       | A list of tags associated with the service.                                                                                                                  |
| providerMetadata  | [PostApiCatalogDiscoveryServicesProviderMetadataData](PostApiCatalogDiscoveryServicesProviderMetadataData.md) | ❌       | Additional metadata from the discovery source provider.                                                                                                      |
