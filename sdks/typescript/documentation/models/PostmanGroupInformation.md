# PostmanGroupInformation

Information about the group.

**Properties**

| Name      | Type     | Required | Description                                       |
| :-------- | :------- | :------- | :------------------------------------------------ |
| id        | number   | ❌       | The group's ID.                                   |
| teamId    | number   | ❌       | The group's Postman team ID.                      |
| name      | string   | ❌       | The group's name.                                 |
| summary   | string   | ❌       | The group's summary.                              |
| createdBy | number   | ❌       | The ID of ther user who created the group.        |
| createdAt | string   | ❌       | The date and time at which the group was created. |
| updatedAt | string   | ❌       | The date and time at which the group was updated. |
| members   | number[] | ❌       | The group members' IDs.                           |
| roles     | string[] | ❌       | The group's roles.                                |
| managers  | number[] | ❌       | The group's managers.                             |
