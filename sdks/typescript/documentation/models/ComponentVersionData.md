# ComponentVersionData

Information about a component's version.

**Properties**

| Name        | Type   | Required | Description                                                                   |
| :---------- | :----- | :------- | :---------------------------------------------------------------------------- |
| id          | string | ❌       | The component version's ID.                                                   |
| label       | string | ❌       | The component version's label.                                                |
| url         | string | ❌       | The URL where the component version can be accessed.                          |
| format      | string | ❌       | The component version's content format.                                       |
| publishedAt | string | ❌       | The date and time at which the component version was published.               |
| content     | string | ❌       | The version's content. This returns when you include the `include` parameter. |
