# TransferWorkspaceToTeamResponseObject

Information about the workspace transfer.

**Properties**

| Name        | Type   | Required | Description                                                 |
| :---------- | :----- | :------- | :---------------------------------------------------------- |
| id          | string | ❌       | The ID of the transferred workspace.                        |
| source      | string | ❌       | The ID of the team the workspace was transferred away from. |
| destination | string | ❌       | The ID of the team that the workspace was transferred to.   |
