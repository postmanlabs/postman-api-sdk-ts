# WorkspaceUpdateCreatedByData

Information about the user that created the workspace update.

**Properties**

| Name     | Type   | Required | Description                                                     |
| :------- | :----- | :------- | :-------------------------------------------------------------- |
| id       | number | ❌       | The user ID of the user that created the workspace update.      |
| name     | string | ❌       | The display name of the user that created the workspace update. |
| username | string | ❌       | The username of the user that created the workspace update.     |
