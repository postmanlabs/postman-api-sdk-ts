# SearchFilterPublisherIsVerified

Filters by publisher verification status. Supported for all element types.

**Properties**

| Name | Type    | Required | Description                                            |
| :--- | :------ | :------- | :----------------------------------------------------- |
| \_eq | boolean | ❌       | If true, return only results from verified publishers. |
| \_ne | boolean | ❌       | If true, exclude results from verified publishers.     |
