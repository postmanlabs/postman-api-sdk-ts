# SearchResourceOrganizationData

Information about the organization that published the resource. This returns a null value for the `user` publisher type.

**Properties**

| Name       | Type    | Required | Description                                       |
| :--------- | :------ | :------- | :------------------------------------------------ |
| id         | string  | ❌       | The organization's ID.                            |
| name       | string  | ❌       | The organization's name.                          |
| isVerified | boolean | ❌       | If true, the organization is verified by Postman. |
