# AuditLogUser

Information about the user.

**Properties**

| Name     | Type   | Required | Description               |
| :------- | :----- | :------- | :------------------------ |
| name     | string | ❌       | The user's name.          |
| username | string | ❌       | The user's username.      |
| email    | string | ❌       | The user's email address. |
| id       | number | ❌       | The user's ID.            |
