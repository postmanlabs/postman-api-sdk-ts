# OrgsInfo

The role assignments keyed by organization ID.

**Properties**

| Name    | Type                        | Required | Description                                                                    |
| :------ | :-------------------------- | :------- | :----------------------------------------------------------------------------- |
| _orgId_ | [TeamRoles](TeamRoles.md)[] | ❌       | A list of the organization's roles. The array's name is the organization's ID. |
