# SearchFilterOrgId

Filters by organization ID. Supported for all element types.

**Properties**

| Name  | Type     | Required | Description                            |
| :---- | :------- | :------- | :------------------------------------- |
| \_eq  | string   | ❌       | The organization ID to match.          |
| \_ne  | string   | ❌       | The organization ID to exclude.        |
| \_in  | string[] | ❌       | A list of organization IDs to match.   |
| \_nin | string[] | ❌       | A list of organization IDs to exclude. |
