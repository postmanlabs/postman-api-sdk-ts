# GetWorkspaceActivityFeedUserData

Information about the user that performed the activity.

**Properties**

| Name      | Type    | Required | Description                                                                                                                                                                    |
| :-------- | :------ | :------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id        | number  | ❌       | The user's ID.                                                                                                                                                                 |
| username  | string  | ❌       | The user's Postman username.                                                                                                                                                   |
| isPartner | boolean | ❌       | If true, the user is a [Partner](https://learning.postman.com/docs/collaborating-in-postman/roles-and-permissions/#partner-team-and-partner-workspace-roles) in the workspace. |
| name      | string  | ❌       | The user's name.                                                                                                                                                               |
