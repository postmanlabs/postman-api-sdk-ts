# GetAnalticsMetadataPaginationData

Information about the metric's pagination parameters.

**Properties**

| Name          | Type     | Required | Description                                       |
| :------------ | :------- | :------- | :------------------------------------------------ |
| supported     | boolean  | ❌       | If true, pagination is supported for this metric. |
| allowedValues | string[] | ❌       | A list of the supported pagination parameters.    |
