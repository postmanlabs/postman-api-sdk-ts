# CreateCollectionSchemaItem

Information about the collection request or folder.

**Properties**

| Name                    | Type                                                                  | Required | Description                                                                                                                                                                                                                                                             |
| :---------------------- | :-------------------------------------------------------------------- | :------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| name                    | string                                                                | ❌       | The item's name.                                                                                                                                                                                                                                                        |
| description             | string                                                                | ❌       | The item's description.                                                                                                                                                                                                                                                 |
| variable                | [CreateCollectionSchemaVariable](CreateCollectionSchemaVariable.md)[] | ❌       | A list of the collection's [variables](https://learning.postman.com/docs/sending-requests/variables/variables/). Make certain not to include sensitive information in variables.                                                                                        |
| event                   | [CreateCollectionSchemaEvent](CreateCollectionSchemaEvent.md)[]       | ❌       | A list of scripts configured to run when specific events occur.                                                                                                                                                                                                         |
| request                 | [ResponseOriginalRequest1](ResponseOriginalRequest1.md)               | ❌       | Information about the collection request.                                                                                                                                                                                                                               |
| response                | [ItemResponse1](ItemResponse1.md)[]                                   | ❌       | A list of the collection's responses.                                                                                                                                                                                                                                   |
| protocolProfileBehavior | [ProtocolProfileBehavior](ProtocolProfileBehavior.md)                 | ❌       | The [settings](https://learning.postman.com/docs/sending-requests/create-requests/request-settings/) used to alter the [Protocol Profile Behavior](https://github.com/postmanlabs/postman-runtime/blob/develop/docs/protocol-profile-behavior.md) of sending a request. |
