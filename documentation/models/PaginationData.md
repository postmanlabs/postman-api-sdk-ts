# PaginationData

Information about the response pagination.

**Properties**

| Name    | Type    | Required | Description                                             |
| :------ | :------ | :------- | :------------------------------------------------------ |
| total   | number  | ❌       | The total number of records available.                  |
| limit   | number  | ❌       | The maximum number of records returned in the response. |
| offset  | number  | ❌       | The number of records skipped.                          |
| hasMore | boolean | ❌       | Indicates whether more are records available.           |
