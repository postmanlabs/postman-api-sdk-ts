# ScimEmailData

Information about the email address.

**Properties**

| Name    | Type    | Required | Description                                             |
| :------ | :------ | :------- | :------------------------------------------------------ |
| primary | boolean | ❌       | If true, the email address is the user's primary email. |
| value   | string  | ❌       | The email address.                                      |
| type    | string  | ❌       | The type of email address.                              |
| display | string  | ❌       | The email address's display name.                       |
