# ApiCatalogDiscoveryServicesProviderMetadata

Additional metadata from the discovery source provider.

**Properties**

| Name                       | Type    | Required | Description                                                                 |
| :------------------------- | :------ | :------- | :-------------------------------------------------------------------------- |
| title                      | string  | ❌       | The provider's service display title.                                       |
| environmentId              | string  | ❌       | The provider's environment ID.                                              |
| environmentVersion         | string  | ❌       | The provider's environment version.                                         |
| openApiSpecCanBeDownloaded | boolean | ❌       | If true, the provider has enabled downloading of the OpenAPI specification. |
