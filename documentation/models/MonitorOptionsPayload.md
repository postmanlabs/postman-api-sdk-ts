# MonitorOptionsPayload

Information about the monitor's option settings.

**Properties**

| Name             | Type                                                                | Required | Description                                                                                                                                                                                                                                                                                                                                   |
| :--------------- | :------------------------------------------------------------------ | :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| followRedirects  | boolean                                                             | ❌       | If true, follow redirects enabled.                                                                                                                                                                                                                                                                                                            |
| requestDelay     | number                                                              | ❌       | The monitor's delay between requests, in milliseconds, as a whole number. A `0` value means no delay. The maximum value is `600000` (10 minutes) on free plans and `900000` (15 minutes) on paid plans. This value is checked only when the value changes.                                                                                    |
| requestTimeout   | number                                                              | ❌       | The monitor's request timeout, in milliseconds, as a whole number. A `null` value means no timeout, and so does omitting it when creating a monitor. A monitor with no timeout returns a `null` value. The maximum value is `600000` (10 minutes) on free plans and `900000` (15 minutes) on paid plans, checked only when the value changes. |
| strictSsl        | boolean                                                             | ❌       | If true, strict SSL enabled.                                                                                                                                                                                                                                                                                                                  |
| requestSelection | [MonitorRequestSelectionPayload](MonitorRequestSelectionPayload.md) | ❌       | The ordered subset of the monitor's collection to run. If set, the monitor runs exactly these items in the given order instead of the full collection. Pass a `null` value to clear the selection and run the full collection again.                                                                                                          |
