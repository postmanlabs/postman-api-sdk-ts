# InvoicesTotal

Information about the invoice's total billed amount.

**Properties**

| Name     | Type   | Required | Description                                                                 |
| :------- | :----- | :------- | :-------------------------------------------------------------------------- |
| value    | number | ❌       | The amount billed.                                                          |
| currency | string | ❌       | The currency of the billed amount. Currently only supports the `USD` value. |
