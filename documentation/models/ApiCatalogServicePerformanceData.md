# ApiCatalogServicePerformanceData

Information about the response time range across all requests in the run.

**Properties**

| Name          | Type   | Required | Description                                            |
| :------------ | :----- | :------- | :----------------------------------------------------- |
| minResponseMs | number | ✅       | The fastest individual response time, in milliseconds. |
| maxResponseMs | number | ✅       | The slowest individual response time, in milliseconds. |
