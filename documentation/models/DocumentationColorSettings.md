# DocumentationColorSettings

The theme's colors, in six digit hexcode. The values in this object must match the hexcode values of either the `light` or `dark` theme defined in the `appearance` object.

**Properties**

| Name         | Type   | Required | Description                                                         |
| :----------- | :----- | :------- | :------------------------------------------------------------------ |
| highlight    | string | ❌       | The hexcode color code for the documentation's highlighting.        |
| rightSidebar | string | ❌       | The hexcode color code for the documentation's right sidebar color. |
| topBar       | string | ❌       | The hexcode color code for the documentation's top bar color.       |
