# BulkWorkspacesRequest

The workspaces to assign to and unassign from the governance group.

**Properties**

| Name   | Type     | Required | Description                                           |
| :----- | :------- | :------- | :---------------------------------------------------- |
| create | string[] | ❌       | The IDs of the workspaces to assign to the group.     |
| delete | string[] | ❌       | The IDs of the workspaces to unassign from the group. |
