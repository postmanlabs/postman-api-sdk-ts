# SearchFilterCollectionId

Filters by collection ID. Supported for `requests` and `collections` only.

**Properties**

| Name  | Type     | Required | Description                          |
| :---- | :------- | :------- | :----------------------------------- |
| \_eq  | string   | ❌       | The collection ID to match.          |
| \_ne  | string   | ❌       | The collection ID to exclude.        |
| \_in  | string[] | ❌       | A list of collection IDs to match.   |
| \_nin | string[] | ❌       | A list of collection IDs to exclude. |
