# CollectionForkData

If the collection is [forked](https://learning.postman.com/docs/collaborating-in-postman/version-control/#forking-postman-entities) from another collection, the fork's information.

**Properties**

| Name      | Type   | Required | Description                                           |
| :-------- | :----- | :------- | :---------------------------------------------------- |
| label     | string | ❌       | The fork's label.                                     |
| createdAt | string | ❌       | The date and time at which the collection was forked. |
| from      | string | ❌       | The source (parent) collection's unique ID.           |
