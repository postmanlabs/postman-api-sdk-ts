# DocumentationCustomizationSettings

Information about the documentation's customization.

**Properties**

| Name       | Type                                                                | Required | Description                                                                                          |
| :--------- | :------------------------------------------------------------------ | :------- | :--------------------------------------------------------------------------------------------------- |
| metaTags   | [DocumentationMetaTags](DocumentationMetaTags.md)[]                 | ❌       | The key-pair values that contain the documentation's `title` and `description` metadata information. |
| appearance | [DocumentationApperanceSettings](DocumentationApperanceSettings.md) | ❌       | Information about the documentation appearance, such as colors and theme.                            |
