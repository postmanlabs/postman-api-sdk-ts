# SearchFilterWorkspaceDocuments

Filters by workspace document ID. Supported for workspace documents.

**Properties**

| Name  | Type     | Required | Description                                  |
| :---- | :------- | :------- | :------------------------------------------- |
| \_eq  | string   | ❌       | The workspace document ID to match.          |
| \_ne  | string   | ❌       | The workspace document ID to exclude.        |
| \_in  | string[] | ❌       | A list of workspace document IDs to match.   |
| \_nin | string[] | ❌       | A list of workspace document IDs to exclude. |
