# MonitorOptions

Information about the monitor's option settings.

**Properties**

| Name            | Type    | Required | Description                                           |
| :-------------- | :------ | :------- | :---------------------------------------------------- |
| followRedirects | boolean | ❌       | If true, follow redirects enabled.                    |
| requestDelay    | number  | ❌       | The monitor's request delay value, in milliseconds.   |
| requestTimeout  | number  | ❌       | The monitor's request timeout value, in milliseconds. |
| strictSsl       | boolean | ❌       | If true, strict SSL enabled.                          |
