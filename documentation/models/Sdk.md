# Sdk

Information about the generated SDK.

**Properties**

| Name        | Type                                                                      | Required | Description                                                                                                                                                                                                                                                                                  |
| :---------- | :------------------------------------------------------------------------ | :------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id          | string                                                                    | ✅       | The SDK's ID.                                                                                                                                                                                                                                                                                |
| language    | [SdkLanguage](SdkLanguage.md)                                             | ✅       | The target output language for the generated SDK.                                                                                                                                                                                                                                            |
| source      | [SdkSource](SdkSource.md)                                                 | ✅       | The collection or specification that the SDK is generated from.                                                                                                                                                                                                                              |
| workspaceId | string                                                                    | ✅       | The ID of the workspace that owns the SDK, derived from the source entity.                                                                                                                                                                                                                   |
| buildStatus | [SdkBuildStatus](SdkBuildStatus.md)                                       | ✅       | The SDK's build lifecycle: - `queued` — Accepted but not yet started. - `in_progress` — The SDK generation is running and in progress. - `succeeded` — The archive is built and available for download. - `failed` — The SDK generation failed. For information, check the `error` response. |
| createdAt   | string                                                                    | ✅       | The date and time at which the SDK was created.                                                                                                                                                                                                                                              |
| updatedAt   | string                                                                    | ✅       | The date and time at which the SDK was last updated.                                                                                                                                                                                                                                         |
| version     | string                                                                    | ❌       | The generated SDK's semantic version ID. This value is automatically assigned by the release/changelog pipeline.                                                                                                                                                                             |
| error       | [SdkErrorBuildStatusFailure](SdkErrorBuildStatusFailure.md)               | ❌       | Information about the SDK build's status when `buildStatus` is `failed`.                                                                                                                                                                                                                     |
| pullRequest | [SimpleSdkGitConnectionPullRequest](SimpleSdkGitConnectionPullRequest.md) | ❌       |                                                                                                                                                                                                                                                                                              |
