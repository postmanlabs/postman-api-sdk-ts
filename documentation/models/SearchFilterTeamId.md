# SearchFilterTeamId

Filters by team ID. Supported for all element types.

**Properties**

| Name  | Type     | Required | Description                    |
| :---- | :------- | :------- | :----------------------------- |
| \_eq  | string   | ❌       | The team ID to match.          |
| \_ne  | string   | ❌       | The team ID to exclude.        |
| \_in  | string[] | ❌       | A list of team IDs to match.   |
| \_nin | string[] | ❌       | A list of team IDs to exclude. |
