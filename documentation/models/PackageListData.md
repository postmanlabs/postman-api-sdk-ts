# PackageListData

**Properties**

| Name        | Type   | Required | Description                                              |
| :---------- | :----- | :------- | :------------------------------------------------------- |
| id          | string | ✅       | The package's unique ID.                                 |
| name        | string | ✅       | The package's immutable, lowercase import name.          |
| description | string | ✅       | The package's description.                               |
| createdAt   | string | ✅       | The date and time at which the package was created.      |
| updatedAt   | string | ✅       | The date and time at which the package was last updated. |
