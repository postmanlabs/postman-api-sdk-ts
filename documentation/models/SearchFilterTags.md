# SearchFilterTags

Filters by tags. Supported for `workspaces` and `collections`.

**Properties**

| Name  | Type     | Required | Description                |
| :---- | :------- | :------- | :------------------------- |
| \_eq  | string   | ❌       | The tag to match.          |
| \_ne  | string   | ❌       | The tag to exclude.        |
| \_in  | string[] | ❌       | A list of tags to match.   |
| \_nin | string[] | ❌       | A list of tags to exclude. |
