# SearchFilterCreatedBy

Filters by the resource creator's user ID. Supported for all element types.

**Properties**

| Name  | Type     | Required | Description                       |
| :---- | :------- | :------- | :-------------------------------- |
| \_eq  | string   | ❌       | The creator ID to match.          |
| \_ne  | string   | ❌       | The creator ID to exclude.        |
| \_in  | string[] | ❌       | A list of creator IDs to match.   |
| \_nin | string[] | ❌       | A list of creator IDs to exclude. |
