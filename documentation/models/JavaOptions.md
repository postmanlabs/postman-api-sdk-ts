# JavaOptions

Java-specific SDK generation options.

**Properties**

| Name       | Type   | Required | Description                                                         |
| :--------- | :----- | :------- | :------------------------------------------------------------------ |
| groupId    | string | ❌       | The Maven group ID written into the `pom.xml` dependencies file.    |
| artifactId | string | ❌       | The Maven artifact ID written into the `pom.xml` dependencies file. |
