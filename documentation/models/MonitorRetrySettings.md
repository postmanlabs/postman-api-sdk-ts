# MonitorRetrySettings

Information about the monitor's retry settings.

**Properties**

| Name     | Type   | Required | Description                                                                                                                                                                                          |
| :------- | :----- | :------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| attempts | number | ❌       | The number of times to reattempt a monitor run if it fails or errors. This may impact your [monitor usage](https://learning.postman.com/docs/monitoring-your-api/monitor-usage/#view-monitor-usage). |
