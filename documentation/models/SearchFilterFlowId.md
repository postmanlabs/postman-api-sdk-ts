# SearchFilterFlowId

Filters by flow ID. Supported for `flows` only.

**Properties**

| Name  | Type     | Required | Description                    |
| :---- | :------- | :------- | :----------------------------- |
| \_eq  | string   | ❌       | The flow ID to match.          |
| \_ne  | string   | ❌       | The flow ID to exclude.        |
| \_in  | string[] | ❌       | A list of flow IDs to match.   |
| \_nin | string[] | ❌       | A list of flow IDs to exclude. |
