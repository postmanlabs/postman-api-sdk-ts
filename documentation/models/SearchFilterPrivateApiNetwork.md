# SearchFilterPrivateApiNetwork

Filters by private API network membership. Supported for all element types.

**Properties**

| Name | Type    | Required | Description                                                              |
| :--- | :------ | :------- | :----------------------------------------------------------------------- |
| \_eq | boolean | ❌       | If true, return only resources that are part of the Private API Network. |
| \_ne | boolean | ❌       | If true, exclude resources that are part of the Private API Network.     |
