# SearchFilterEnvironmentId

Filters by environment ID. Supported for `environments` only.

**Properties**

| Name  | Type     | Required | Description                           |
| :---- | :------- | :------- | :------------------------------------ |
| \_eq  | string   | ❌       | The environment ID to match.          |
| \_ne  | string   | ❌       | The environment ID to exclude.        |
| \_in  | string[] | ❌       | A list of environment IDs to match.   |
| \_nin | string[] | ❌       | A list of environment IDs to exclude. |
