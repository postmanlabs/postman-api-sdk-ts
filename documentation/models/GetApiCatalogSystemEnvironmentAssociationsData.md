# GetApiCatalogSystemEnvironmentAssociationsData

Information about the workspace-environment association.

**Properties**

| Name                   | Type   | Required | Description                                             |
| :--------------------- | :----- | :------- | :------------------------------------------------------ |
| id                     | string | ✅       | The association's ID.                                   |
| workspaceEnvironmentId | string | ✅       | The workspace environment's ID.                         |
| workspaceId            | string | ✅       | The ID of the workspace that contains the environment.  |
| associatedAt           | string | ✅       | The date and time at which the association was created. |
