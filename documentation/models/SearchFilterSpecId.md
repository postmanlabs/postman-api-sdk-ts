# SearchFilterSpecId

Filters by specification ID. Supported for `specs` only.

**Properties**

| Name  | Type     | Required | Description                             |
| :---- | :------- | :------- | :-------------------------------------- |
| \_eq  | string   | ❌       | The specification ID to match.          |
| \_ne  | string   | ❌       | The specification ID to exclude.        |
| \_in  | string[] | ❌       | A list of specification IDs to match.   |
| \_nin | string[] | ❌       | A list of specification IDs to exclude. |
