# CollectionItem

Information about the collection request or folder.

**Properties**

| Name                    | Type                                                    | Required | Description                                                                                                                                                                                                                                                             |
| :---------------------- | :------------------------------------------------------ | :------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id                      | string                                                  | ✅       | The collection item's ID.                                                                                                                                                                                                                                               |
| name                    | string                                                  | ❌       | The item's name.                                                                                                                                                                                                                                                        |
| description             | string                                                  | ❌       | The item's description.                                                                                                                                                                                                                                                 |
| variable                | [CollectionVariable](CollectionVariable.md)[]           | ❌       | A list of the collection's [variables](https://learning.postman.com/docs/sending-requests/variables/variables/). Make certain not to include sensitive information in variables.                                                                                        |
| event                   | [CollectionEvent](CollectionEvent.md)[]                 | ❌       | A list of scripts configured to run when specific events occur. These scripts can be referenced in the collection by their ID.                                                                                                                                          |
| request                 | [ResponseOriginalRequest2](ResponseOriginalRequest2.md) | ❌       | Information about the collection request.                                                                                                                                                                                                                               |
| response                | [ItemResponse2](ItemResponse2.md)[]                     | ❌       | A list of the collection's responses.                                                                                                                                                                                                                                   |
| protocolProfileBehavior | [ProtocolProfileBehavior](ProtocolProfileBehavior.md)   | ❌       | The [settings](https://learning.postman.com/docs/sending-requests/create-requests/request-settings/) used to alter the [Protocol Profile Behavior](https://github.com/postmanlabs/postman-runtime/blob/develop/docs/protocol-profile-behavior.md) of sending a request. |
| createdAt               | string                                                  | ❌       | The date and time at which the collection item was created.                                                                                                                                                                                                             |
| updatedAt               | string                                                  | ❌       | The date and time at which the collection item was updated.                                                                                                                                                                                                             |
| uid                     | string                                                  | ❌       | The collection item's unique ID.                                                                                                                                                                                                                                        |
