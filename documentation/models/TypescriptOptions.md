# TypescriptOptions

TypeScript-specific SDK generation options.

**Properties**

| Name    | Type   | Required | Description                                                  |
| :------ | :----- | :------- | :----------------------------------------------------------- |
| npmOrg  | string | ❌       | An npm organization's scope. Don't include a trailing slash. |
| npmName | string | ❌       | The unscoped npm package's name.                             |
