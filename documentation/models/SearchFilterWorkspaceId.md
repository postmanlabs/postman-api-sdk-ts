# SearchFilterWorkspaceId

Filters by workspace ID. Supported for all element types.

**Properties**

| Name  | Type     | Required | Description                         |
| :---- | :------- | :------- | :---------------------------------- |
| \_eq  | string   | ❌       | The workspace ID to match.          |
| \_ne  | string   | ❌       | The workspace ID to exclude.        |
| \_in  | string[] | ❌       | A list of workspace IDs to match.   |
| \_nin | string[] | ❌       | A list of workspace IDs to exclude. |
